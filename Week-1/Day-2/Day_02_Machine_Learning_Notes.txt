--------------------------------------------------
1. WHAT IS MACHINE LEARNING?
--------------------------------------------------

Machine Learning (ML) is a subset of Artificial Intelligence (AI)
that enables computers to learn patterns from data and make
predictions without being explicitly programmed.

Traditional Software:
Data + Rules = Output

Machine Learning:
Data + Output = Model (Learns Rules)

--------------------------------------------------
2. WHY MACHINE LEARNING EXISTS
--------------------------------------------------

Some problems are too complex for manually written rules.

Examples:
- Face Recognition
- Fraud Detection
- Recommendation Systems
- Speech Recognition
- Chatbots

Instead of writing thousands of rules, we allow the model to
learn patterns from historical data.

--------------------------------------------------
3. TRADITIONAL PROGRAMMING VS MACHINE LEARNING
--------------------------------------------------

Traditional Programming:

Input Data
+
Rules Written By Developer
=
Output

Example:
Age >= 18 => Eligible

Machine Learning:

Historical Data
+
Correct Answers
=
Model

New Data
+
Model
=
Prediction

--------------------------------------------------
4. CORE COMPONENTS OF MACHINE LEARNING
--------------------------------------------------

A. DATA
-------
Data is the fuel of Machine Learning.

Examples:
- Employee Records
- Customer Transactions
- Email Messages
- Medical Records

Without data there is no learning.

--------------------------------------------------

B. FEATURES
-----------
Features are input variables used for prediction.

Examples:

Salary Prediction:
- Experience
- Education
- Skills
- Location

Resume Screening:
- Experience
- Skills
- Degree

Features = Inputs

--------------------------------------------------

C. LABEL
---------
Label is the expected output.

Examples:

Salary Prediction:
Label = Salary

Spam Detection:
Label = Spam / Not Spam

Resume Screening:
Label = Selected / Rejected

Label = Target Variable

--------------------------------------------------

D. MODEL
---------
A Model is the knowledge learned from training data.

Process:

Data
 ↓
Training
 ↓
Model
 ↓
Prediction

The model stores learned patterns.

--------------------------------------------------
5. TRAINING
--------------------------------------------------

Training is the process of teaching a model using historical data.

Example:

Experience | Salary
--------------------
1 Year     | 300000
3 Years    | 500000
5 Years    | 800000

The model learns relationships between experience and salary.

Result:
A trained model capable of making predictions.

--------------------------------------------------
6. PREDICTION
--------------------------------------------------

After training:

New Input Data
 ↓
Model
 ↓
Prediction

Example:

Experience = 6 Years
Skills = .NET + Angular

Prediction:
Salary ≈ Expected Value

8. AI VS ML VS DEEP LEARNING
--------------------------------------------------

Artificial Intelligence (AI)
    |
    +-- Machine Learning (ML)
            |
            +-- Deep Learning (DL)

AI:
Machines performing intelligent tasks.

ML:
Machines learning from data.

DL:
Advanced ML using Neural Networks.
