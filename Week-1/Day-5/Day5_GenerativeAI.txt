  SECTION 1 — WHAT IS GENERATIVE AI?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  DEFINITION:
    Generative AI (Gen AI) is a type of Artificial Intelligence that can CREATE 
    new content — text, images, audio, video, code — by learning patterns from 
    massive amounts of existing data.

    It doesn't just classify or predict (like Day 4's neural networks).
    It GENERATES something NEW that did not exist before.

  DISCRIMINATIVE vs GENERATIVE AI:

    Discriminative AI:   Looks at data and CLASSIFIES it.
                         Example: "Is this email spam or not spam?"
                         It draws boundaries between categories.

    Generative AI:       Learns the data distribution and CREATES new data.
                         Example: "Write me a new email in this style."
                         It generates brand-new samples from learned patterns.

  SIMPLE ANALOGY:
    Discriminative AI = A Judge who looks at paintings and says "Real or Fake?"
    Generative AI     = An Artist who CREATES new paintings from scratch.

  THE CORE IDEA:
    Generative AI is trained on HUGE datasets:
      - Text Gen models  → billions of web pages, books, articles
      - Image Gen models → hundreds of millions of images + captions
      - Audio Gen models → thousands of hours of music, speech, sound

    After training, the model has learned the "statistical patterns" of human 
    language, images, and sound — and can generate realistic new examples.

  .NET DEVELOPER PERSPECTIVE:
    As a .NET developer, Generative AI is what powers:
      • GitHub Copilot   → writes C# code for you
      • Azure OpenAI     → lets you add ChatGPT to your ASP.NET apps
      • Semantic Kernel  → Microsoft's SDK to build AI agents in .NET
    
    Gen AI is not just a research topic — it's a production tool you will 
    use directly in your .NET projects within the next few years (or now!).

  SECTION 2 — TEXT GENERATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  DEFINITION:
    Text generation is the ability of an AI model to produce coherent, 
    contextually relevant, human-like text based on an input prompt.

  THE TECHNOLOGY BEHIND IT — Large Language Models (LLMs):
    Text generation is powered by LLMs (Large Language Models).
    LLMs are massive neural networks trained on enormous text datasets 
    to understand and generate human language.

    "Large" = billions of parameters (weights in the neural network)
    Examples:
      GPT-4:    ~1.8 trillion parameters (estimated)
      LLaMA 3:  ~70 billion parameters
      Claude 3: ~hundreds of billions (exact not disclosed)

  THE ARCHITECTURE — TRANSFORMER:
    Modern LLMs are built on the TRANSFORMER architecture (2017, Google).
    Key innovation: the "Attention Mechanism"

    ATTENTION MECHANISM (simplified):
      When generating each word, the model "attends to" (focuses on) 
      all relevant words in the input — not just the previous word.

      Example:
        "The cat sat on the mat because IT was tired."
        The model must understand "IT" refers to "cat" — even though 
        it's far back in the sentence. Attention handles this.

    SELF-ATTENTION IN ONE LINE:
      Every word looks at every other word and decides how much to 
      "pay attention" to each one when generating the next token.

  HOW TEXT GENERATION WORKS STEP BY STEP:
  
    STEP 1 — TOKENIZATION:
      Input text is broken into tokens (words or sub-words).
      "Hello world" → [15496, 995]  (token IDs in GPT vocabulary)

    STEP 2 — EMBEDDING:
      Each token is converted to a dense vector (list of numbers)
      that captures its meaning in high-dimensional space.
      "King" and "Queen" will be close in this space.

    STEP 3 — TRANSFORMER LAYERS:
      The token vectors flow through many Transformer layers.
      Each layer refines understanding using Attention + Feed-Forward networks.

    STEP 4 — NEXT TOKEN PREDICTION:
      The model outputs a PROBABILITY DISTRIBUTION over all possible 
      next tokens. The most likely token is selected (or sampled).
      
      Input: "The sky is"
      Probabilities: {"blue": 0.72, "red": 0.08, "green": 0.05, ...}
      Selected: "blue"

    STEP 5 — AUTOREGRESSIVE GENERATION:
      The selected token is appended to the input, and the process 
      repeats. Token by token, the full response is generated.

      "The" → "The sky" → "The sky is" → "The sky is blue and beautiful."

  TRAINING PROCESS:
    
    PRE-TRAINING:
      The model is trained on massive internet-scale text data.
      Task: "Predict the next word" (self-supervised learning)
      No labels needed — the text itself IS the label.
      This builds general language understanding.

    FINE-TUNING (RLHF):
      After pre-training, the model is fine-tuned using 
      Reinforcement Learning from Human Feedback (RLHF):
        1. Human raters rank multiple model responses
        2. A reward model is trained on these preferences
        3. The LLM is updated to produce responses humans prefer
      This makes the model helpful, harmless, and honest.

  KEY PARAMETERS THAT CONTROL OUTPUT:
    
    Temperature:   Controls randomness.
                   0.0 = deterministic (always most likely token)
                   1.0 = creative/random
                   Use low temp for code/factual answers, high for creative writing.
    
    Top-p:         Nucleus sampling — only consider tokens whose cumulative 
                   probability exceeds p (e.g., 0.9). Balances quality + diversity.
    
    Max Tokens:    Maximum length of generated response.
    
    System Prompt: Instructions given to the model before the conversation.
                   Used to set persona, rules, output format, etc.

  REAL-WORLD APPLICATIONS:
    • Code generation (GitHub Copilot, Cursor)
    • Customer support chatbots
    • Document summarization
    • Email drafting and auto-reply
    • Legal document analysis
    • Content creation (blogs, product descriptions)
    • SQL query generation from natural language
    • API documentation generation

  SECTION 3 — IMAGE GENERATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  DEFINITION:
    Image generation is the ability of an AI model to create new, realistic 
    (or artistic) images from a text description, sketch, or other image input.

  THE TWO MAIN TECHNOLOGIES:

  ─────────────────────────────────────────────────────────
  3.1 DIFFUSION MODELS (Modern Standard)
  ─────────────────────────────────────────────────────────
    Used by: Stable Diffusion, DALL·E 3, Midjourney, Adobe Firefly

    CORE IDEA:
      The model learns to DENOISE images. 
      Start with pure random noise → gradually remove noise → get a clean image.

    HOW IT WORKS:
    
      TRAINING PHASE:
        1. Take a real image
        2. Gradually ADD random noise to it (over ~1000 steps)
        3. Until the image becomes pure noise
        4. Train the neural network to REVERSE this process
           (learn to predict and remove the noise at each step)
      
      INFERENCE (Generating new images):
        1. Start with pure random noise
        2. The neural network denoises it step by step
        3. Conditioned on a text prompt (via CLIP embeddings)
        4. After ~20-50 steps, a clear image matching the prompt emerges
    
    ANALOGY:
      Imagine a sculptor starting with a rough rock (noise) and 
      chipping away carefully step by step until a statue (image) emerges.
      The text prompt guides WHAT sculpture to make.

    TEXT-TO-IMAGE PIPELINE (Stable Diffusion):
      
      Text Prompt
          ↓
      Text Encoder (CLIP) → Text Embeddings
          ↓
      Latent Diffusion (U-Net) ← guided by text embeddings
          ↓
      Latent Image (compressed)
          ↓
      VAE Decoder → Final High-Res Image

    KEY COMPONENT — CLIP:
      CLIP (Contrastive Language-Image Pretraining) by OpenAI
      Trained on (image, text) pairs to understand what images 
      "look like" for a given text description.
      Bridges the gap between language and vision.

  ─────────────────────────────────────────────────────────
  3.2 GANs (Generative Adversarial Networks) — Older Approach
  ─────────────────────────────────────────────────────────
    Used by: StyleGAN, DeepFake tech, early image generators

    CORE IDEA:
      Two neural networks compete against each other:
        GENERATOR:     Creates fake images from random noise
        DISCRIMINATOR: Tries to distinguish real vs fake images
      
      They play a game:
        Generator:     "Is THIS image convincing enough?"
        Discriminator: "No, I can still tell it's fake."
        Generator:     learns → tries again → gets better
        
      Eventually the Generator creates images so realistic 
      the Discriminator can't tell them apart.

    ANALOGY:
      Generator = Forger trying to make fake currency
      Discriminator = Bank inspector trying to catch fakes
      They keep improving each other. Eventually the forger is 
      so good even experts can't tell the difference.

    WHY DIFFUSION MODELS REPLACED GANS:
      GANs were hard to train (mode collapse, unstable training)
      Diffusion models are more stable and produce higher quality results.

  IMAGE GENERATION CAPABILITIES:
    • Text-to-Image:    "A cat wearing a top hat, watercolor style"
    • Image-to-Image:  Transform an existing image in a new style
    • Inpainting:      Fill in / replace parts of an existing image
    • Outpainting:     Extend an image beyond its original borders
    • Style Transfer:  Apply one image's artistic style to another
    • Super Resolution: Upscale a low-res image to high resolution

  REAL-WORLD APPLICATIONS:
    • E-commerce product image generation (reduce photography costs)
    • Game asset creation (textures, environments, characters)
    • Marketing and advertising visuals
    • Architecture and interior design visualization
    • Fashion design prototyping
    • Medical imaging enhancement (MRI super-resolution)
    • Film and VFX concept art

  POPULAR TOOLS:
    DALL·E 3       → OpenAI. Integrated into ChatGPT Plus. Best prompt adherence.
    Midjourney     → Best aesthetic quality. Discord-based. Subscription.
    Stable Diffusion → Open source. Run locally on GPU. Highly customizable.
    Adobe Firefly  → Commercially safe. Integrated in Photoshop/Illustrator.
    Imagen 3       → Google's image model. Integrated in Gemini.

  .NET DEVELOPER EXAMPLE:
    Generate product images via OpenAI API in C#:

    var imageClient = openAIClient.GetImageClient("dall-e-3");
    
    ImageGenerationOptions options = new()
    {
        Quality = GeneratedImageQuality.High,
        Size = GeneratedImageSize.W1792xH1024,
        Style = GeneratedImageStyle.Natural,
        ResponseFormat = GeneratedImageFormat.Uri
    };
    
    GeneratedImage image = await imageClient.GenerateImageAsync(
        "A professional product photo of a blue running shoe on white background", 
        options);
    
    Uri imageUri = image.ImageUri;
    // Now save to Azure Blob Storage or serve to frontend

  SECTION 4 — AUDIO GENERATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  DEFINITION:
    Audio generation is the ability of an AI model to create new audio content — 
    speech, music, sound effects, or voice clones — from text, melody, or examples.

  THREE MAIN CATEGORIES:

  ─────────────────────────────────────────────────────────
  4.1 TEXT-TO-SPEECH (TTS)
  ─────────────────────────────────────────────────────────
    Converts written text into natural-sounding spoken audio.

    HOW IT WORKS:
      Text → Phonemes/Tokens → Acoustic Model → Waveform/Audio

    Modern TTS is powered by neural networks (WaveNet, Tacotron, VITS)
    that generate raw audio waveforms — vastly better than robotic rule-based TTS.

    KEY FEATURES OF MODERN NEURAL TTS:
      • Natural prosody (rhythm, stress, intonation)
      • Emotion and tone control
      • Multiple voice options
      • Speed/pitch customization
      • Near-human quality

    POPULAR TOOLS:
      ElevenLabs   → Highest quality TTS + voice cloning. Free + paid tiers.
      OpenAI TTS   → 6 voices, very natural. Accessible via API.
      Azure Speech → Microsoft's enterprise TTS. 400+ voices, 140 languages.
      Google TTS   → Integrated in Google Cloud. Neural voices available.
      Murf.ai      → Studio-quality voiceovers. Good for content creators.

    .NET DEVELOPER EXAMPLE (OpenAI TTS via API):

      var audioClient = openAIClient.GetAudioClient("tts-1-hd");
      
      BinaryData audio = await audioClient.GenerateSpeechAsync(
          "Hello! Your order has been confirmed and will arrive in 3 days.",
          GeneratedSpeechVoice.Nova);
      
      await File.WriteAllBytesAsync("order_confirmation.mp3", audio.ToArray());
      // Serve this MP3 in your ASP.NET Core API response or Azure Blob Storage

    REAL-WORLD APPLICATIONS:
      • Accessibility features (screen readers, visually impaired users)
      • IVR systems (phone customer support automation)
      • E-learning narration without hiring voice actors
      • Podcast generation / audiobooks
      • In-app notifications and alerts (voice responses)
      • Navigation apps (turn-by-turn voice directions)

  ─────────────────────────────────────────────────────────
  4.2 MUSIC GENERATION
  ─────────────────────────────────────────────────────────
    AI creates original music tracks from text descriptions or style references.

    HOW IT WORKS:
      Uses Transformer or Diffusion models trained on massive music datasets.
      Text prompt or style input → generates MIDI or raw audio waveforms.

    POPULAR TOOLS:
      Suno AI    → Text-to-song with vocals and instruments. "A rock song about rain"
      Udio       → High-quality music + lyrics generation.
      MusicGen   → Meta's open-source music generation model.
      Stable Audio → Stability AI's audio diffusion model. No vocals.
      AIVA       → AI composer for film/game scores. Professional use.

    EXAMPLE PROMPT:
      "An upbeat lo-fi hip hop track with jazz piano, soft drums, and rain sounds, 
       suitable for studying"
      → Suno generates a full 3-minute song with these characteristics.

    REAL-WORLD APPLICATIONS:
      • Background music for videos, podcasts, apps
      • Royalty-free music for content creators
      • Personalized jingle creation for brands
      • Game soundtrack generation
      • Therapeutic / ambient music for apps

  ─────────────────────────────────────────────────────────
  4.3 VOICE CLONING & SPEECH PROCESSING
  ─────────────────────────────────────────────────────────
    VOICE CLONING:
      AI can replicate a specific person's voice from a short audio sample.
      Provide 10-60 seconds of someone speaking → AI clones their voice.
      Then text-to-speech can be generated IN THAT VOICE.
      
      Tools: ElevenLabs (Voice Cloning), Resemble AI, Azure Custom Neural Voice

    SPEECH-TO-TEXT (ASR — Automatic Speech Recognition):
      Converts spoken audio → text. Not generation, but crucial in the pipeline.
      Whisper by OpenAI — state-of-the-art, open source, 99 languages.
      
      .NET Example:
        var transcription = await audioClient.TranscribeAudioAsync("meeting.mp3");
        string transcript = transcription.Value.Text;
        // Feed this text into an LLM to summarize the meeting!

    FULL AUDIO PIPELINE EXAMPLE FOR .NET APP:
      
      1. User speaks into microphone (browser/mobile)
      2. Audio sent to your ASP.NET Core API endpoint
      3. Whisper (Speech-to-Text) → converts speech to text
      4. GPT-4 / Claude (Text Generation) → processes the query
      5. OpenAI TTS / ElevenLabs → converts response back to speech
      6. Audio streamed back to user
      
      Result: A fully voice-powered AI assistant in your .NET application!

  SECTION 5 — MAJOR AI MODELS: ChatGPT, Gemini, Claude
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  These are the three dominant Large Language Model (LLM) platforms available 
  today. Each is built by a different company with different philosophies.

  ─────────────────────────────────────────────────────────
  5.1 ChatGPT (by OpenAI)
  ─────────────────────────────────────────────────────────
    COMPANY:    OpenAI (founded 2015, backed by Microsoft)
    MODELS:     GPT-3.5, GPT-4, GPT-4o, GPT-4.1, o1, o3
    ACCESS:     chat.openai.com | API via platform.openai.com

    HISTORY:
      • 2020: GPT-3 (175B parameters) — breakthrough in text generation
      • Nov 2022: ChatGPT launched — reached 1 million users in 5 days
        (fastest product to reach 1 million users in history at the time)
      • Mar 2023: GPT-4 — multimodal (text + images), significantly smarter
      • 2024: GPT-4o ("omni") — handles text, image, audio in one model
      • 2024-25: o1, o3 — "reasoning models" with chain-of-thought thinking

    KEY FEATURES:
      ✦ GPT-4o: Multimodal — text, image, file, audio input/output
      ✦ Code Interpreter: Executes Python code, analyzes data, creates charts
      ✦ Web Browsing: Real-time internet search integration
      ✦ Image Generation: DALL·E 3 integration for image creation
      ✦ Custom GPTs: Build your own chatbot without coding
      ✦ Plugins/Actions: Connect to external APIs and tools
      ✦ Voice Mode: Real-time voice conversation with emotion

    REASONING MODELS (o1, o3):
      OpenAI's "thinking" models. Before answering, they perform internal 
      chain-of-thought reasoning (like solving a math problem step by step).
      Significantly better at: math, coding, science, logic problems.
      Trade-off: slower and more expensive than GPT-4o.

    PRICING (approx 2025):
      Free:  GPT-4o-mini access, limited GPT-4o
      Plus:  $20/month → Full GPT-4o + DALL·E + web browsing
      API:   Pay-per-token (input: ~$2.50 / 1M tokens for GPT-4o)

    .NET DEVELOPER INTEGRATION:
      Microsoft's Azure OpenAI Service → deploy OpenAI models in Azure
      with enterprise security, compliance, and no data leaving your tenant.
      
      Install: dotnet add package Azure.AI.OpenAI
      
      var client = new AzureOpenAIClient(
          new Uri("https://your-resource.openai.azure.com/"),
          new AzureKeyCredential(Environment.GetEnvironmentVariable("AZURE_OAI_KEY")));
      
      This is the #1 choice for .NET teams in enterprise environments.

    STRENGTHS:
      ✓ Largest ecosystem (plugins, GPTs, integrations)
      ✓ Best multimodal capabilities (text + vision + voice)
      ✓ Best code generation (powers GitHub Copilot)
      ✓ DALL·E integration for image creation
      ✓ Deep Azure/Microsoft integration (ideal for .NET teams)

    WEAKNESSES:
      ✗ Expensive at scale
      ✗ Data privacy concerns (without Azure deployment)
      ✗ Context window (128K) smaller than Claude
      ✗ Occasionally "hallucinates" (makes up facts confidently)

  ─────────────────────────────────────────────────────────
  5.2 GEMINI (by Google DeepMind)
  ─────────────────────────────────────────────────────────
    COMPANY:    Google DeepMind (Google + DeepMind merged AI teams)
    MODELS:     Gemini 1.0, Gemini 1.5, Gemini 2.0, Gemini 2.5
    ACCESS:     gemini.google.com | API via Google AI Studio / Vertex AI

    HISTORY:
      • 2023: Google's Bard launched (predecessor to Gemini)
      • Dec 2023: Gemini 1.0 announced — Nano, Pro, Ultra tiers
      • Feb 2024: Bard rebranded to Gemini. Gemini Advanced launched.
      • May 2024: Gemini 1.5 Pro — 1 MILLION token context window
      • 2025: Gemini 2.0, 2.5 — multi-step reasoning + live streaming

    UNIQUE STRENGTHS:
      ✦ Natively Multimodal: built from scratch for text, image, audio, video
      ✦ 2 Million Token Context: Gemini 1.5 Pro can process entire codebases
      ✦ Deep Google Integration: Search, Gmail, Docs, YouTube, Maps, Workspace
      ✦ Real-time Streaming: Gemini 2.0 Flash can process live video/audio
      ✦ Google Search Grounding: Responses anchored to real Google Search results

  SECTION 8 — INTERVIEW QUESTIONS & ANSWERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Q1: What is Generative AI and how does it differ from traditional AI?
  A:  Traditional AI (discriminative) classifies or predicts from existing data.
      Generative AI creates NEW data (text, images, audio) by learning the 
      underlying patterns and probability distributions of its training data.

  Q2: What is an LLM? Name three examples.
  A:  A Large Language Model is a neural network with billions of parameters 
      trained on vast text data to understand and generate human language.
      Examples: GPT-4 (OpenAI), Gemini Ultra (Google), Claude Opus (Anthropic).

  Q3: What is the Transformer architecture and why is it important?
  A:  Transformer is a neural network architecture (introduced 2017 by Google) 
      that uses Self-Attention to process all tokens in parallel and relate 
      any token to any other. It replaced RNNs and enabled training of much 
      larger models. It is the foundation of every modern LLM.

  Q4: What is the attention mechanism in simple terms?
  A:  Attention allows each token (word) to look at all other tokens and decide 
      how relevant each is when determining meaning. For example, in "The cat 
      sat on the mat because it was tired", the model uses attention to understand 
      "it" refers to "cat" by attending to the relevant part of the sentence.

  Q5: What is temperature in LLMs? When would you set it low vs high?
  A:  Temperature controls randomness. At 0, the model always picks the most 
      likely next token (deterministic). At 1+, randomness increases. Use low 
      temperature (0.1-0.3) for factual/code tasks, high (0.7-1.0) for creative 
      writing, brainstorming, and generating diverse outputs.

  Q6: What is a Diffusion Model? How does it generate images?
  A:  A Diffusion Model is trained to reverse a "noising" process. During training, 
      noise is gradually added to images. The model learns to reverse this — going 
      from pure noise back to a clean image. At inference time, it starts with 
      random noise and progressively denoises it, guided by a text prompt.

  Q7: What is a GAN and how does it differ from a Diffusion model?
  A:  A GAN uses two competing networks: a Generator that creates fake images and 
      a Discriminator that distinguishes real from fake. They improve each other 
      through adversarial training. Diffusion models are more stable, produce 
      higher quality results, and have largely replaced GANs for image generation.

  Q8: What is a context window in LLMs?
  A:  The context window is the maximum amount of text (measured in tokens) an 
      LLM can process in a single request — both input and output combined. 
      GPT-4o: 128K, Claude: 200K, Gemini 1.5: 1M tokens. Larger context windows 
      allow processing of entire documents, books, or codebases at once.

  Q9: What is hallucination in AI and how can you reduce it?
  A:  Hallucination is when an LLM generates false information confidently. 
      It happens because models generate statistically plausible text, not 
      factually verified text. Mitigation: RAG (Retrieval-Augmented Generation) 
      — ground the model's responses in retrieved, verified documents. Also 
      use low temperature, ask the model to cite sources, and verify outputs.

  Q10: What is RLHF and why is it important?
  A:   RLHF (Reinforcement Learning from Human Feedback) is a training technique 
       where human raters rank model outputs, a reward model is trained on these 
       rankings, and the LLM is updated to maximize reward (human preference). 
       It makes models helpful, harmless, and aligned with human values.

  Q11: What is Constitutional AI (Anthropic's approach)?
  A:   Anthropic's method of training Claude using a "constitution" — a set of 
       principles the AI must follow. The model is trained to critique its own 
       outputs against these principles and revise them, reducing reliance on 
       human feedback for safety training. Makes Claude more consistently safe.

  Q12: How would you integrate an LLM into a .NET Web API?
  A:   For OpenAI/Azure OpenAI: use the Azure.AI.OpenAI NuGet package.
       Create a service that calls the API with a system prompt and user message.
       For Claude: use HttpClient to POST to api.anthropic.com/v1/messages.
       For enterprise apps, use Azure OpenAI for compliance and data security.
       Semantic Kernel is Microsoft's recommended SDK for multi-model .NET apps.

  Q13: What is RAG (Retrieval-Augmented Generation)?
  A:   RAG is a pattern where before generating a response, the system retrieves 
       relevant documents from a knowledge base (vector database) and includes 
       them in the prompt as context. This grounds the model's response in 
       verified, up-to-date information and reduces hallucination. Common in 
       enterprise AI apps built with .NET + Azure AI Search + OpenAI.

  Q14: What is the difference between GPT-4o and o1/o3 reasoning models?
  A:   GPT-4o is a general-purpose multimodal model — fast, handles text/image/
       audio, good at most tasks. The o1/o3 reasoning models use chain-of-thought 
       reasoning internally (they "think before answering"). They are significantly 
       better at math, logic, coding, and science problems, but are slower and 
       more expensive. Use o1/o3 for complex reasoning, GPT-4o for everyday tasks.
